# 智能体档案与管理会话

智能体的身份随档案目录保存，可以由多个原生会话承载。档案内的 `AGENTS.md` 是通用入口，`SOUL.md` 定义自我与交流原则，`ROLE.md` 可以写长期职责，也可以留空。职责本身不授予操作权限。

## 定位档案和当前任务

先按[接入规则](access.md)核对 Home。以调用方实际的档案目录为路径，调用 `ne project resolve --path PATH` 或 `project_resolve {path}`。命中智能体档案时，用 `assistant.id` 确认长期身份，从 `assistant.archive_directory` 读取档案文件。返回的项目 ID 用于查询项目和项目任务。目录未识别时按实际结果说明，勿按项目名称或会话标题猜测身份。

另按[身份发现](identity.md)确认本次会话的 Session ID，用于收发信件和参与协作。新会话等待绑定时可以先读取档案，或读取用户明确指定的任务。

从用户指定的任务开始。需要找回工作时，按[任务管理](task.md)定位相关项目中的任务。多个任务符合时确认本次范围，再查事项、协作摘要或[历史记忆](memory.md)。任务目标、进展、验证和交接依据记录在任务及事项中。普通对话按用户要求开展。

## 项目管理与协作

管理会话从档案目录启动，可以讨论需求、拆解任务、查阅进展和核对交付。工程会话从目标项目目录启动。用户需要双方参与协作时，可以把智能体项目和目标工程项目加入任务范围，再在协作室选择两边的会话。

在用户授权派工时，按[信箱规则](mailbox.md)联系指定的执行会话。消息包含任务或事项 ID、预期结果、验收条件和回复所用的会话 ID。核实返回的证据后再更新任务事项。

需要开启工程会话时，用 `ne session new --agent AGENT --cwd ABSOLUTE_ENGINEERING_DIRECTORY --message TEXT` 或 `session_start`。结果先给出终端 ID，使用 `session terminals` 等待真实会话绑定。

协作室由用户开启及指定成员。收到邀请后按[任务协作](collaboration.md)加入，使用当前会话的成员身份和本次运行赋予的职责。
