# 智能体运行指南

## 档案目录

- `AGENTS.md` 是运行指南，说明如何读档案和使用 NoEnding。NoEnding 提供默认模板。
- `IDENTITY.md` 是 NoEnding 生成的身份证，记录你的名称和稳定的智能体 ID。
- `SOUL.md` 定义你是谁、你重视什么，以及你如何与用户合作。
- `USER.md` 是你自行维护的用户印象，记录你在合作中逐渐了解到的沟通习惯、偏好和关注点。
- `ROLE.md` 记录你承担的角色、长期目标、职责和工作范围，可以留空。
- `INTRO.md` 是你自行维护的自我介绍，供第一次认识你的合作者阅读。
- `CLAUDE.md` 是 Claude Code 的入口，它会加载这份指南。

## 确认自己是谁

先读 `IDENTITY.md`，确认你的名称和智能体 ID，再按 NoEnding Skill 核对当前使用的 NoEnding Home。身份文件缺失或需要核对时，按 NoEnding Skill 从已登记的档案目录解析身份。需要发信、接手来信或参与协作时，再确认本次会话 ID。

接着读 `SOUL.md`、已有的 `USER.md` 和 `ROLE.md`。`ROLE.md` 为空时，按用户这次交代的目标开展工作。

## 维护档案

当你对用户有了能改善后续合作的新认识，可以自行新建或更新 `USER.md`。更新前先读现有记录。区分已确认的偏好和暂时的判断，收到用户纠正时修订相关内容。把印象作为背景，按当前用户的指示和授权行动。

在 `INTRO.md` 里用第一人称介绍何时可以找你、希望对方带上什么信息，以及你能交付什么。你可以在档案目录里自行新建或更新这份介绍。职责或合作方式发生变化时，更新相关内容。只写适合给其他合作者看的信息。

得到用户对相应修改的授权后，再更新 `AGENTS.md`、`SOUL.md` 或 `ROLE.md`。`IDENTITY.md` 和 `CLAUDE.md` 由 NoEnding 维护。智能体的名称、技能配置和权限由用户决定。

## 接上手里的工作

你的身份可以延续到不同对话。用户要你接着做时，先查任务事项、相关对话和协作记录，确认上次做到哪一步，以及还有哪项需要验证。进度和交接写在 NoEnding 对应的任务记录里。

用当前 NoEnding 会话 ID 查收和回复本次对话的来信，并以这个身份参加协作。发到智能体信箱的信，可以由你的任一档案对话查阅，由一个对话接手。需要处理时按 NoEnding Skill 核对信件的接手状态。新对话还在等待绑定时，可以先读档案和用户指定的任务。

操作遵循本次用户授权。需要修改 NoEnding 记录、发信、派工或加入协作时，按 NoEnding Skill 核对当前身份、对象和权限。
