# 格式 12 → 13 一次性迁移

这是独立的离线工具，应用启动不执行迁移。格式 13 的摘要只接受事项列表 JSON，不兼容旧 Markdown 摘要。

工具保留会话、原始消息、投影、项目、任务、关联、偏好、设置和搜索索引的全部数据及 ID。旧会话、任务、项目摘要全部清空，不转换旧正文；摘要消费进度也清空。任务与项目版本推进并标记待更新，会话下次提取从第一条当前有效消息开始。

先退出 NoEnding，并在整个操作期间保持关闭。在仓库 `src-tauri` 目录执行：

```sh
cargo run --example migrate_v12 -- --database /绝对路径/noending.db --backup-dir /绝对路径/backups
```

默认备份、生成并校验候选库，实际库保持不变。检查输出后，加 `--apply` 才替换实际库：

```sh
cargo run --example migrate_v12 -- --database /绝对路径/noending.db --backup-dir /绝对路径/backups --apply
```

工具校验数据库身份和精确版本，持有独占锁，使用 SQLite 备份纳入 WAL 中的数据。新摘要表使用 `storage/schema.rs` 定义，其余表逐表双向核对所有行和列，并检查外键、数据库完整性及 FTS 索引。原格式完整备份保留旧摘要。工具拒绝重复迁移和其他格式；验证失败不替换实际库。

恢复时关闭应用，使用完整备份及支持格式 12 的旧版程序；不要混用不同库的 WAL/SHM 文件。更新后的程序只接受格式 13。旧版 11 → 12 一次性工具已移除，本次仅处理格式 12。
