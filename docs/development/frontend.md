# 前端开发规范

修改前端前阅读本文，并检查受影响组件的当前实现、调用方和测试。本文维护已落地的公共约定；工程结构、测试设计和验证要求见 [AGENTS.md](../../AGENTS.md)。临时方案与调查放在 `.tmp/docs/`，不在这里记录修改历史或各页面的实现细节。

## 样式与主题

沿用现有视觉语言。相同角色使用相同组件和变量；新增通用变体应扩展公共实现，业务页面不另做一套外观。

| 位置 | 职责 |
| --- | --- |
| [`tokens.css`](../../src/styles/tokens.css) | 语义颜色、字体、间距、圆角、控件及图标尺寸、动效等视觉变量 |
| [`global.css`](../../src/styles/global.css)、[`components.css`](../../src/styles/components.css) | 通用控件、卡片、列表、弹窗与交互外观 |
| [`layout.css`](../../src/styles/layout.css) | 应用外壳、标题栏、侧栏与页面布局 |
| `features/` 下的业务样式 | 专属布局与业务状态，不重复定义公共外观 |

背景按职责分层，左右详情区使用相同内容底板：

| 变量 | 用途 |
| --- | --- |
| `--bg-chrome` | 顶部标题栏与固定导航外框 |
| `--bg-sidebar` | 左侧会话导航 |
| `--bg-canvas` | 看板、详情与设置的内容底板 |
| `--bg-surface` | 卡片与弹层 |
| `--bg-panel` | 内嵌区域 |
| `--bg-app` | 聊天与终端画布 |

颜色通过语义变量适配明暗主题，不在业务样式里硬编码颜色。普通按钮的悬停、按下底色不能覆盖实色按钮的语义底色；危险实色按钮使用 `--danger-solid` 和 `--on-solid`，危险文字与图标使用 `--danger`。同时检查普通、悬停、按下、焦点及禁用状态。

图标沿用 `Icon` 与公共图标按钮规格：导航与页面标题使用 18px（`--icon-size`），卡片标题、列表对象及普通操作使用 16px（`--icon-size-sm`），辅助状态、小型操作和选择器箭头使用 14px（`--icon-size-xs`）。功能图标共用 18×18 绘制坐标、`--icon-stroke-width` 描边与圆角端点，通常留出约 2px 绘制边距；箭头等开放图形按视觉重量校准，不强行拉满。

矩形容器使用轻圆角轮廓；消息、文件夹及归档等同类图标共用基础形状。内部细节只保留识别所需，保证 14px 时仍清晰；立体项目、折角和箭头按语义保留棱角，不把所有图形改成圆角。

视觉偏小或偏移时修改公共图形，不在业务页面另加缩放、描边或零散尺寸。`AgentIcon` 保留品牌形状与颜色，绘制范围按同档功能图标校准；默认尺寸由公共样式决定，显式尺寸只使用 14、16、18px。图标大小与按钮点击范围分开控制；弹窗标题区的图标按钮共用尺寸、间距与交互样式，不混用页面内的小型操作规格。

## 公共组件

优先复用以下入口，新增需求先检查公共组件是否已有相应能力：

| 用途 | 公共入口 |
| --- | --- |
| 页面标题栏 | `PageHeader` 的 `icon`、`navigation`、`actions` 槽位 |
| 看板搜索与筛选 | `BoardToolbar`，业务页只提供筛选内容和状态 |
| 下拉选择与操作菜单 | `CustomSelect`、`PopupMenu` |
| 弹窗与底部操作 | `common.Modal`、`DialogActions` |
| 错误反馈与空状态 | `Notice`、`EmptyState` |
| 详情展示卡片 | `DetailSection`，标题、数量、状态与操作留在公共标题区 |
| 详情列表与属性 | `DetailList`、`DetailListRow`、`DetailFields`、`common.Field` |
| 双区详情、侧栏及固定输入 | `DetailPanelProvider`、`DetailLayout`、`DetailPanelFooter` |
| 侧栏开关与宽度调整 | `PanelToggle`、`PanelResizer` |

不在业务页手工拼接公共标题栏的布局或分隔线。属性字段沿用公共标签、字段值、复制按钮和间距；内容正文按语义使用普通文本、Markdown 或事项排版，不另造卡片外壳。

## 内容分区与长内容

主区展示核心内容，右栏展示属性、关联对象和辅助信息。两侧独立滚动，避免在已有滚动区内继续叠加同类滚动容器；看板保留整页滚动。

长列表和正文按公共规格限高滚动，标题及操作留在外层，短内容自然收缩。滚动条靠容器边缘，并为行尾操作预留空间；滚动区应可聚焦，支持键盘阅读。

关联对象列表使用左侧图标、名称，右侧状态与操作的行结构；补充信息放名称下方。行主入口与行尾操作独立，不嵌套按钮。对象默认最近更新在前，会话按最近活动排序，无可靠时间时保留语义顺序。

列表路径用 `CompactPath`，属性路径全文换行；悬停、打开与复制始终使用完整路径，不从截断后的显示文字恢复路径。

终端输入通过 `DetailPanelFooter` 固定在右栏底部。收起右栏不能销毁终端、丢失草稿或改变输入权限；终端尺寸应随可用空间更新。终端 TUI 的隐藏输入层与文档排版不套用应用控件样式。

## 跳转、加载与状态记忆

跳转统一经过 [`navigation.ts`](../../src/app/navigation.ts) 的导航预备，代码与页头数据就绪后再切页，前进和后退也使用同一入口。不要在业务页另建一套切换流程来处理闪烁。

首屏预备由 [`navigationData.ts`](../../src/app/navigationData.ts) 统一协调，复用页面缓存与读取资源，准备主列表及影响首帧的轻量数据。不要额外预取全部消息历史、技能或插件包目录、Agent 运行选项来阻塞跳转；这些按需读取。主读取失败时保留可用的当前页，辅助读取失败由目标卡片提供错误与重试。准备较久时使用公共延迟进度提示，新导航或目标删除后，旧请求不能切回页面或留下进度状态。

看板首次读取统一使用 `BoardLoading`，短读取不立即插入骨架，读取完成前不显示“暂无数据”。有数据时的后台刷新保留列表、操作和页面框架，不以清空内容表示正在刷新。

侧栏与页面的终端数据共用 `createLiveReadResource`，连续事件合并读取，同一资源只保留一个在途请求，期间有变更再补读且不发布过期结果。侧栏收起或隐藏时只记录待刷新；重新显示时补读，永久删除立即移除。已知前端数据变更通过 `notifyDataChanged` 声明影响的侧栏集合，无关修改传空集合；未声明范围的后台通知保守刷新，不凭推测跳过。

加载期间保留页面骨架与已读取内容；重新读取不应先清空已有卡片。子页切换保留共同标题栏及其焦点，复用 `PageHeaderHost` 等既有公共机制，不通过重建页头或立即显示临时占位制造过渡。

右侧栏的展开状态与宽度按以下范围持久化记忆，切换同组子页或不同对象时沿用：

| 页面组 | 共享范围 |
| --- | --- |
| 任务 | 任务详情、协作室 |
| 会话 | 会话详情、历史消息、终端 |
| 其他详情 | 项目、Agent、技能、插件包各自记忆 |

主区卡片折叠按页面类型及卡片类型记忆；同组子页共有的右栏卡片按页面组及卡片类型共用折叠状态，与整个右栏的展开偏好分开保存。折叠时保留正文组件、草稿、滚动位置及正在执行的操作，标题与操作入口保持可用。

界面状态使用现有 `useViewState`、`useViewPreference` 和读取缓存机制，区分临时状态与需要重启后恢复的偏好。持久化偏好需要校验，不把无效旧值直接用于布局。

## 键盘、焦点与平台边界

图标按钮保留明确的可访问名称与悬停提示。菜单、选择器、弹窗和侧栏沿用公共的焦点与 Escape 行为；关闭内层弹窗或菜单时，不能同时关闭外层界面。保留键盘操作及输入法组合输入，不把组合输入中的 Enter 当成提交。

保留 macOS 与 Windows 的字体、路径和窗口行为。标题内容与按钮可正常操作，标题栏空白区域可拖动窗口，不通过扩大拖动区覆盖交互元素。

验证范围遵循 [AGENTS.md 的验证要求](../../AGENTS.md#验证要求)。根据改动检查受影响的明暗主题、宽窄布局、长内容和交互状态；平台尚未实测时明确说明，不将浏览器预览当作原生平台验证。
